# ToDo App

Небольшое приложение для управления списком задач. Написал его, чтобы попрактиковаться в асинхронном JavaScript — `Promises`, `async/await`, работа с REST API через `fetch`, динамическое обновление DOM.

Версия: `1.0.0`

## Цель

Разобрался на практике с несколькими вещами:

- Параллельная загрузка данных через `Promise.all()` — задачи и пользователи тянутся одновременно;
- Полный цикл CRUD через Fetch API (`GET`, `POST`, `PATCH`, `DELETE`);
- Обработка ошибок — `try...catch` плюс проверка `response.ok`;
- Изоляция области видимости через IIFE, чтобы ничего не торчало в глобале;
- Аккуратное снятие обработчиков (`removeEventListener`) при удалении элементов — чтобы не плодить утечки памяти.

## Что умеет

- При старте подгружает задачи (лимит 15) и пользователей (лимит 5) с тестового сервера.
- Можно добавить задачу и привязать её к пользователю — уходит `POST`.
- Отметить задачу выполненной или вернуть в активные — `PATCH`.
- Удалить задачу из интерфейса и с сервера (`DELETE`). Отдельно обрабатывается случай с локально созданной мок-задачей (`id: 201`).
- Если сеть упала или сервер ответил чем-то невнятным — покажет уведомление.

## Стек

- Vanilla JavaScript (ES6+), без фреймворков и сборки
- `async/await`, `Promise.all`, Fetch API
- Mock-бэкенд: [JSONPlaceholder (Cypress mirror)](https://cypress.io)

## Как устроен код

Всё завёрнуто в `(function () { ... })()` и разложено на три слоя:

1. **Basic logic** — рендеринг и удаление DOM-элементов: `printTodo`, `createUserOption`, `removeTodo`.
2. **Event logic** — инициализация и обработка действий пользователя: `initApp`, `handleSubmit`, `handleTodoChange`, `handleClose`.
3. **Async logic** — сеть и API: `getAllTodos`, `getAllUsers`, `createTodo`, `toggleTodoComplete`, `deleteTodo`.
